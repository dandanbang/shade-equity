## Access paths (documented, not downloaded)
- **Land surface temperature**: Landsat 8/9 C2 L2 (`ST_B10`, 30 m, scale 0.00341802 + 149.0 K) via Planetary Computer STAC `landsat-c2-l2` (bbox 121.45,24.96,121.67,25.21; pick cloud<20, Jun-Sep) or GEE `LANDSAT/LC09/C02/T1_L2`. Sentinel-2 L2A (10 m NDVI/NDBI) is `sentinel-2-l2a`. Coarser: GEE `YALE/YCEO/UHI/UHI_yearly_pixel/v4` (300 m SUHI, 2003-2018); MODIS `MOD11A1` (1 km). No official Taipei LST layer on data.taipei found; TCCIP (tccip.ncdr.nat.gov.tw) lists 都市熱島 thermal-comfort map downloads (license unchecked).
- **Canopy height**: Meta/WRI 1 m global canopy height (AWS Open Data `dataforgood-fb-data/forests/v1/`; GEE asset ID unverified) — tiles are large, not fetched. Planetary Computer `io-lulc-annual-v02` (10 m LULC 2017-2023) is a lighter alternative.
- **Buildings**: Overture Maps buildings (`overturemaps download --bbox=121.45,24.96,121.67,25.21 -f geoparquet --type=building`) or Google Open Buildings; not fetched (use for shade-casting and free-ground estimation).
- **Tree removal history**: Official lookup is the interactive 行道樹路燈資訊網 (https://geopkl.gov.taipei/) 移樹履歷 query by 行政區/里; no bulk download or API found. Data.taipei tree files carry no removal flag. 

## Gaps and proposed substitutes
1. **Removal records (the 3,164 trees of 2025)**: not open. Substitute: snapshot TaipeiTree.csv/ParkTree.csv regularly and diff by TreeID (disappeared IDs = removals), or simulate: sample ~3,164 street trees as "removed", weighted toward large diameters/older species, and label them simulated. Using the geopkl 移樹履歷 query for a few 里 can validate the simulation.
2. **Low-income households by 里**: not found (only city/district-level, no 里). Substitute: proxy index from 65+ share, MOF/NTA household income by 里 (財政部統計資料 綜合所得稅各里, not fetched), or simulate with clear label.
3. **Heat/LST**: no ready file. Substitute: compute from Landsat via STAC (path above) in a 10-line script, or use WorldCover built-up % per 里 as heat proxy.
4. **Canopy per 里**: not precomputed. Substitute: tree-point counts / DBH-derived crown area per 里 from tree CSVs + WorldCover class 10 fraction.
5. **Pedestrian volume**: only MRT OD (station level, links in index) and bus stop points. Substitute: density of exits/bus stops/schools/markets/care sites within 200 m of sidewalk polygons.
6. **Empty-pit status, soil volume, overhead wires/underground utilities**: not open. Substitute: nearest-tree distance to each pit; assume utilities unknown and mark candidates "needs survey".
7. **Park polygons / elder-site coordinates / school coordinates**: use OSM (ODbL) and geocode addresses.
